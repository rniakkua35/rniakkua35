■ 1. 設置場所
---------------------------------------------------------
自分のGitHubユーザー名と「完全に同じ名前」のリポジトリを作る。
  例）ユーザー名が riku-dev → リポジトリ名も riku-dev
  ・Public にする（必須）
  ・"Add a README file" にチェック
  ・ルートに README.md を置く

■ 2. 蛇アニメ（contribution snake）の設定
---------------------------------------------------------
.github/workflows/snake.yml を作成:

name: Generate Snake
on:
  schedule: [{ cron: "0 0 * * *" }]
  workflow_dispatch:
  push: { branches: [main] }
jobs:
  build:
    runs-on: ubuntu-latest
    permissions: { contents: write }
    steps:
      - uses: Platane/snk@v3
        id: snake-gif
        with:
          github_user_name: ${{ github.repository_owner }}
          outputs: |
            dist/github-snake.svg
            dist/github-snake-dark.svg?palette=github-dark
      - uses: crazy-max/ghaction-github-pages@v4
        with:
          target_branch: output
          build_dir: dist
        env:
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}

→ 初回は Actions タブから手動実行（Run workflow）してください。
